# C++ Data Structures

A collection of C++ assignments and practice exercises from a 2024 data structures course.
2024년 자료구조 수업에서 작성한 C++ 과제와 실습 코드를 모아둔 저장소입니다.

## Labs

### Lab 5 — C++ Fundamentals
Practice with conditionals, loops, structures, and basic problem solving, including date calculations, score summaries, and Roman numeral conversion.
조건문, 반복문, 구조체와 기본 문제 해결을 연습했습니다. 날짜 계산, 점수 요약, 로마 숫자 변환 등을 구현했습니다.

[View Lab 5 and screenshots](./lab5)

### Lab 6 — Arrays, Pointers, and Functions
Practice with dynamically allocated arrays, pointers, functions, string handling, and data comparison.
동적 배열, 포인터, 함수, 문자열 처리와 데이터 비교를 연습했습니다.

[View Lab 6 and screenshots](./lab6)

### Lab 7 — Classes and Objects
Use classes to organize student and score data, validate input, and calculate results.
학생과 점수 데이터를 클래스로 관리하고, 입력값을 검증해 결과를 계산했습니다.

[View Lab 7 and screenshots](./lab7)

### Lab 9 — Stack
Implement stack operations such as `push`, `pop`, and printing with an array-based stack.
배열 기반 스택을 구현하고 `push`, `pop`, 출력 기능을 연습했습니다.

[View Lab 9 and screenshots](./lab9)

### Lab 10 — Linked Stack
Implement a stack using linked nodes and support operations such as `push`, `pop`, `peek`, and `clear`.
연결 노드를 이용해 스택을 구현하고 `push`, `pop`, `peek`, `clear` 기능을 만들었습니다.

[View Lab 10 and screenshots](./lab10)

### Lab 11 — Circular Queue
Implement and inspect enqueue and dequeue operations in a circular queue.
원형 큐의 `enqueue`와 `dequeue` 동작을 구현하고 내부 상태를 확인했습니다.

[View Lab 11 and screenshots](./lab11)

### Lab 12 — Queue Class
Organize queue operations in a separate class and use a menu-driven program to interact with the queue.
큐 기능을 별도 클래스로 구성하고 메뉴 기반 프로그램에서 큐를 조작했습니다.

[View Lab 12 and screenshots](./lab12)

### Lab 13 — Sorting
Implement selection sort and display the values as they are sorted.
선택 정렬을 구현하고 정렬 과정을 출력했습니다.

[View Lab 13 and screenshots](./lab13)

### Lab 14 — Binary Trees
Build a binary tree from input values and traverse it using inorder traversal.
입력값으로 이진 트리를 구성하고 중위 순회로 노드를 출력했습니다.

[View Lab 14 and screenshots](./lab14)

### Lab 15 — Stack and Heap Practice
Practice stack operations with character input and use a heap to find the k-th largest value.
문자 입력을 스택으로 처리하고 힙을 이용해 k번째로 큰 값을 찾았습니다.

[View Lab 15 and screenshots](./lab15)
